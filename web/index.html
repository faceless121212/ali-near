    What is Near6?
    
        
    Near6 is Ali's payment protocol for NEAR. It lets any API charge per request.
    
      
    
      
    
        
    
          
    Built on a web standard
    
          
    The web has a status code for payments: 402 Payment Required. Near6 uses it. The API answers 402 with a price, the agent pays, then asks again with proof.
    
        
    
        
    
          
    Made for NEAR
    
          
    Every payment goes through the agent's wallet contract, which checks your limits first. The API confirms the USDC transfer on-chain before it answers.
    
        
    
        
    
          
    Familiar to builders
    
          
    Near6 uses the same message format as x402, Coinbase's open payment standard. Tools and agents that know x402 will feel at home.

    app.get("/weather",
  paywall({ ledger, price: USDC(0.01),
            payTo: "weather-api.near", asset: "usdc.near" }),
  (req, res) => res.json(getWeather(req)));
